# ホッケーバトル 🏒

スマホで遊べる、かんたんエアホッケー。
4歳でも遊べるように、ルールも操作もできるだけシンプルにしています。

## 遊びかた

1. タイトルの **ゲームスタート** をタッチ（ふわふわ浮いています）
2. **ひとりで あそぶ**（左・コンピューターと対戦）か
   **ふたりで あそぶ**（右）をえらぶ
3. **ステージ**をえらぶ（アイス・もり・うみ・マグマ の4つ）。
   ステージごとに**パックのデザインも変わります**
4. **じゃんけん**で先行後攻を決める。勝った方にパックがきます
5. **3・2・1** のカウントのあと、**笛の合図**でパックが転がってスタート
6. **5点先取**で勝ち。勝った方には**トロフィーと「かち」**、
   負けた方には「まけ」が出ます。おわったら画面をタップで もういちど

- 画面の**下半分がプレイヤー1（青）**、**上半分がプレイヤー2（赤）**
- 自分のマレットを**指でスライドして動かす**だけ
- ふたりのときは2人同時に指を動かせます（マルチタッチ対応）
- ゴールが決まると「**ゴール！**」が飛び出し、ゴール口から光がはじけます
- ゴールのあとは、**点を入れられた方**からパックが転がって再開します
- **そっと当てればゆっくり、強く打てば速く**飛びます。音と振動も強さに応じて変わります。
  **本当に強く振ったときだけ**「バシーン！」という専用の音が鳴り、振動も強めの3連になります。
  止まっているマレットに当たったときは、あまり弾みません。
  当たりの強さは「指を動かした速さ」に比例します（マレットの速さは数コマぶんならして使っています）
- パックが壁に当たると、**軽く火花が散ります**（強く当たるほど多く飛びます）
- パックが壁とマレットに挟まったときは、真ん中へ逃がします（連続で壁にぶつかり続けません）

### ほし集めと必殺技

- 対戦中、**自分の陣地にほしがときどき現れます**（くるくる回りながら出てきます）
- マレットで触ると集められます。**3つ集めると必殺技**が使えます
- 集めた数は、自分のゴールがわの角に表示されます（○が3つ→集めるとほしに変わる）
- 3つそろうと、自分のゴールの**左右の角に光るボタンが2つ**出ます。
  **どちらの技を出すか選べます**（どちらも、ほしはリセットされます）

| ボタン | 技 | どうなるか |
| --- | --- | --- |
| 左（雷） | **しびれ** | 相手のマレットを3秒間動けなくする |
| 右（3つのパック） | **ぶんれつ** | つぎに自分が打った1発で、パックが3つに分かれる |

- **しびれ**は、発動すると**相手に雷が落ち、当たったところから左右に雷が走ります**。
  しびれている間は、相手のマレットが雷をまとって小刻みに震えます
- **ぶんれつ**は押してもすぐには出ません。**つぎに自分がパックを打った瞬間**に
  左右へ広がる3つのパックになります。構えているあいだは、パックのそばに
  うすい分身が2つ見えるので分かります
- 分かれたパックは**どれが入っても得点**になります。7秒ほどで消えて、もとの1つに戻ります
- ひとりで遊ぶときは、コンピューターはほしを集めず、必殺技も使いません（自分だけが使えます）
- 途中でスコアを0に戻したいときは、左はしの「↺」を**長押し**
- タイトルに戻りたいときは、右はしの「🏠」を**長押し**
  （どちらも、子どもが誤って触っても効かないよう短いタップでは反応しません）
- ステージ選択・ひとり／ふたりの画面は、左上の「◀」で1つ前に戻れます

じゃんけんは、同じ画面を2人で見るため、**2人そろうまで選んだ手は伏せられます**。
あいこなら自動でやり直し。ひとりで遊ぶときはコンピューターが自動で出します。

コンピューターはかなり手加減しています（マレットが遅い・狙いがずれる・ときどき休む）。

音楽はタイトルと対戦中で切り替わります。

インストール不要のWebアプリ（PWA）です。ホーム画面に追加すると、
アドレスバーのない全画面で起動し、オフラインでも遊べます。

## 画面の大きさについて

スマホ・タブレット・折りたたみ（Fold）など、画面の形が違っても
**盤面の形が崩れないように**しています。

- 細長い画面 … 盤面を画面いっぱいに広げる
- 正方形に近い画面・タブレット … 盤面を中央に置き、左右のあきは
  飾りの絵（`side.jpg`）でうめる

盤面の縦横比は `AR_MAX`（0.60）と `AR_MIN`（0.40）の範囲に収めています。
パックの速さも画面ではなく**盤面の幅**を基準にしているので、
どの端末でも同じ手ごたえになります。

人のマレットは**指の位置そのもの**です（遅れません）。速く指を動かしても
パックを飛び越さないよう、1コマの中で動く量に応じて計算の刻みを増やしています。

さらに、ブラウザが指の位置を届けるまでの遅れを埋めるため、指の速さから
**1コマぶん先を予測**して動かしています（`LEAD_TIME`）。指を止めれば
予測はすぐ消えるので、行き過ぎて戻ることはありません。

## スマホで遊べるようにする（GitHub Pages）

1. GitHubでこのリポジトリを開く
2. **Settings → Pages**
3. **Source** で `Deploy from a branch` を選ぶ
4. Branch に `claude/two-player-hockey-game-ru3mcn` ／ フォルダは `/ (root)` を選んで **Save**
5. 1〜2分待つと URL が表示されます
   （`https://tsuyoshistyleball-collab.github.io/hockey/`）

その URL をスマホのChromeで開けば、すぐ遊べます。

## ホーム画面に追加してアプリにする

**Android / Chrome**
1. 上のURLをChromeで開く
2. 右上の「⋮」→ **アプリをインストール**（または「ホーム画面に追加」）
3. ホーム画面のアイコンから起動 → 全画面・縦向き固定で立ち上がります

**iPhone / Safari**
1. 上のURLをSafariで開く（iPhoneではSafariから追加する必要があります）
2. 下の共有ボタン → **ホーム画面に追加**

一度開いておけば、電波がなくても遊べます。

## バージョンと自動更新

タイトル画面の**左下に小さくバージョン**が出ます（例 `v3.6.0`）。
更新したかどうかは、ここを見れば分かります。

更新はできるだけ早く届くようにしてあります。

- HTMLとmanifestは毎回サーバーを見に行く（キャッシュを使わない）
- アプリを開いたとき・**画面に戻ってきたとき**・1分ごとに、新しい中身がないか確認する
- 新しい中身が用意できたら、その場で自動で読み直す

それでも古いままのときは、GitHub Pages側の反映待ち（1〜2分）か、
端末のキャッシュが残っている場合です。Chromeで「⋮ → 履歴 → 閲覧データの削除」を試してください。
**ホーム画面のアイコンだけ**が古いときは、Androidがインストール時のアイコンを保持しているためなので、
一度アンインストールして入れ直してください。

### 更新するときにやること

中身を変えたら、次の2か所を必ず上げてください。上げないと古いままになります。
`sw.js` の `CACHE` を上げると、画像や音もサーバーから取り直します
（同じファイル名のまま絵を差し替えても、古いものが残りません）。

| ファイル | 場所 |
| --- | --- |
| `index.html` | `APP_VERSION`（画面左下に出る番号） |
| `sw.js` | `CACHE`（`hockey-v34` の数字） |

ライブラリは使っていません。

ステージは `index.html` の `STAGES` に並んでいます。盤面の絵ごとに、
壁とゴールの位置を画像サイズに対する割合で指定します。
ステージを増やすときは、ここに1行足して `sw.js` の `ASSETS` にも画像を追加してください。

```js
var STAGES = [
  { key:'ice', src:'field-3.jpg', puck:'puck-ice.png', tc:'#1a1a20',
    fld:{ x0:0.0680, x1:0.9278, y0:0.0826, y1:0.9223, mid:0.4926, goal:0.1629, circle:0.093 } },
  ...
];
// src … 盤面の絵 / puck … そのステージのパック / tc … パックの残像の色
```

```js
// x0/x1/y0/y1 … 壁の位置（氷のふちではなく、壁ぎわに寄せてある）
// mid          … センターラインの位置。絵の真ん中とずれていてもここで合わせる
// goal         … ゴールの半分の幅
// circle       … センターサークルの半径（スコアの丸を置く位置に使う）
```

`goal` はゴールの網の見た目とぴったり合わせてあります。広げすぎると、
網の外にあるパックまで得点になってしまうので注意してください。

## 調整したいとき

`index.html` の値を変えるだけで調整できます。

| 変数 | 意味 | 既定値 |
| --- | --- | --- |
| `WIN_SCORE` | 何点先取で勝ちか | `5` |
| `PUCK_MAX` | パックの最高速度（盤面の幅/秒）。小さいほど遅くてやさしい | `2.25` |
| `LEAD_TIME` | 指の動きを何秒ぶん先読みするか。0にすると先読みなし | `0.020` |
| `AI_SPEED` | コンピューターのマレットの速さ。小さいほど弱い | `0.95` |
| `REST` | 止まっているマレットに当たったとき、どれだけ返るか | `0.35` |
| `HIT_MIN` / `HIT_MAX` | そっと／強く当てたとき、マレットの速さの何倍でパックが飛ぶか | `0.46` / `1.70` |
| `HIT_COOL` | 同じマレットが続けて当たらない時間（秒） | `0.09` |
| `SMASH_AT` | この強さ以上で当たると強打の音になる（0〜1） | `0.75` |
| `STAR_NEED` | 必殺技に必要なほしの数 | `3` |
| `STAR_MIN` / `STAR_MAX` | 次のほしが出るまでの秒数 | `4.5` / `8.5` |
| `ZAP_TIME` | 相手がしびれている秒数 | `3.0` |
| `SPLIT_ANG` | 分かれたパックが左右に開く角度（ラジアン） | `0.34` |
| `SPLIT_LIFE` | 分かれたパックが消えるまでの秒数 | `7.0` |
| `GOAL_TIME` | ゴール演出の長さ（秒） | `1.6` |
| `AR_MAX` / `AR_MIN` | 盤面の縦横比の上限・下限 | `0.60` / `0.40` |
| `CD_STEP` | カウントダウン1つぶんの秒数（3・2・1で3倍かかる） | `0.8` |
| `RESET_HOLD` | リセットの長押し秒数 | `0.9` |
| `JK_WAIT` | じゃんけんで片方しか選ばないとき、自動で決めるまでの秒数 | `8` |

コンピューターをさらに弱くしたいときは、`updateAI()` の中の
「狙いのブレ（`errX`）」を大きく、「休む確率（`0.22`）」を上げてください。
再開時にパックが転がる速さは `serve()` の `0.44 * F.w` です。

## 音楽について

`title.mp3` と `battle.mp3` は市販ゲームの楽曲です。ご家庭で遊ぶぶんには問題ありませんが、
GitHub Pages で公開すると第三者に配布することになるため、著作権上の問題があります。
公開したまま使う場合は、フリー素材の曲に差し替えることをおすすめします。
差し替えるときは、同じ名前のファイルを置き換えるだけです。
