# ホッケー 🏒

スマホで2人あそべる、かんたんエアホッケー。
4歳でも遊べるように、ルールも操作もできるだけシンプルにしています。

- 画面の**下半分がプレイヤー1（青）**、**上半分がプレイヤー2（赤）**
- 自分のマレットを**指でスライドして動かす**だけ
- 2人が同時に指を動かせます（マルチタッチ対応）
- 試合のはじめは**じゃんけん**で先行後攻を決めます。
  自分の側の ✊ ✌️ ✋ から1つタップ。**勝った方にパックがきます**
  （相手に見えないよう、選んだ手は2人そろうまで伏せられます。あいこならもう一度）
- 開始と再開は **3・2・1 のカウントダウン**。数字と矢印が出て、
  そのあと**点を入れられた方にパックがゆっくり転がって**始まります
- **5点先取**で勝ち。おわったら画面をタップで もういちど
- 途中でスコアを0に戻したいときは、左はしの「↺」を**長押し**
  （子どもが誤って触らないよう、短いタップでは戻りません）

インストール不要のWebアプリ（PWA）です。ホーム画面に追加すると、
アドレスバーのない全画面で起動し、オフラインでも遊べます。

## スマホで遊べるようにする（GitHub Pages）

1. GitHubでこのリポジトリを開く
2. **Settings → Pages**
3. **Source** で `Deploy from a branch` を選ぶ
4. Branch に `claude/two-player-hockey-game-ru3mcn` ／ フォルダは `/ (root)` を選んで **Save**
5. 1〜2分待つと URL が表示されます
   （`https://tsuyoshistyleball-collab.github.io/hockey/`）

その URL をスマホのChromeで開けば、すぐ遊べます。

## ホーム画面に追加してアプリにする

**Android / Chrome**
1. 上のURLをChromeで開く
2. 右上の「⋮」→ **アプリをインストール**（または「ホーム画面に追加」）
3. ホーム画面のアイコンから起動 → 全画面・縦向き固定で立ち上がります

**iPhone / Safari**
1. 上のURLをSafariで開く（iPhoneではSafariから追加する必要があります）
2. 下の共有ボタン → **ホーム画面に追加**

一度開いておけば、電波がなくても遊べます。

## アイコンや画面が古いままのとき

一度開いたページはオフライン用にキャッシュされるため、更新がすぐ反映されないことがあります。
HTMLとmanifestは毎回サーバーを見に行くようにしてありますが、それでも古いままなら次を試してください。

**まだインストールしていない場合**
1. Chromeでページを開き、右上「⋮」→ 履歴 → **閲覧データの削除**（キャッシュ）
2. ページを開き直す

**すでにホーム画面に追加している場合**
Androidはインストール時のアイコンを保持するため、アイコンだけは入れ直しが必要です。
1. ホーム画面のアイコンを長押しして**アンインストール**
2. Chromeでページを開き直して、もう一度「アプリをインストール」

## 中身

| ファイル | 役割 |
| --- | --- |
| `index.html` | ゲーム本体（HTML + Canvas + JavaScript、これ1枚で完結） |
| `manifest.json` | PWA設定（アプリ名・アイコン・全画面・縦向き） |
| `sw.js` | Service Worker。オフライン用のキャッシュ |
| `icon-192-2.png` / `icon-512-2.png` / `icon-512-maskable-2.png` | ホーム画面アイコン |

ライブラリは使っていません。`index.html` をブラウザで直接開いても遊べます
（そのときだけ Service Worker は動きません）。

## 調整したいとき

`index.html` の先頭あたりの値を変えるだけで調整できます。

| 変数 | 意味 | 既定値 |
| --- | --- | --- |
| `WIN_SCORE` | 何点先取で勝ちか | `5` |
| `PUCK_MAX` | パックの最高速度（画面幅/秒）。小さいほど遅くてやさしい | `1.55` |
| `MAL_SPEED` | マレットが指に追いつく速さ | `3.0` |
| `RESET_HOLD` | リセットの長押し秒数 | `0.9` |
| `CD_STEP` | カウントダウン1つぶんの秒数（3・2・1で3倍かかる） | `0.8` |
| `JK_WAIT` | じゃんけんで片方しか選ばないとき、自動で決めるまでの秒数 | `8` |

ゴールの大きさは `goalHalfWidth()`、マレットとパックの大きさは `layout()` の中にあります。
再開時にパックが転がる速さは `serve()` の `0.42 * W` です。
小さい子には `PUCK_MAX` を下げて、ゴールを大きくすると遊びやすくなります。
